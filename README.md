# Open Climate Bench

A documented, reproducible benchmark of public climate datasets and model evals.

Status: idea. Part of [Bat City AI](https://batcityai.com)'s Year One programs.

## Plan

- **Data**: public climate and energy datasets (TBD — kept to one dataset for v0
  to avoid scope creep)
- **Stack**: Python, Hugging Face Datasets
- **Goal v0**: 2-3 baseline models (e.g. persistence, linear, XGBoost) benchmarked
  against one public dataset, with results in a static leaderboard

Nothing shipped yet. See [Issues](../../issues) for current plan.
